# The basemap

ATGreen draws its data on a **self-hosted, open-source basemap**: a
[Protomaps](https://protomaps.com) planet build of OpenStreetMap, served as a single
`.pmtiles` file from this site's own origin and rendered by
[MapLibre GL JS](https://maplibre.org). There is no map API key, no third-party tile
host, no quota and no bill.

It replaced Mapbox in September 2026. This file is the server half of that change; the
code half is `src/js/map.js` and `scripts/build-basemap-style.mjs`.

## Why self-hosted, and not a free hosted service

Three reasons, the first of which is not optional:

1. **The Content-Security-Policy.** The atgreen vhost enforces
   `connect-src 'self' https://api.mapbox.com https://events.mapbox.com`. Any other tile
   host is blocked in production and the map renders blank. Serving the basemap from
   `/basemap/` on this origin needs no CSP exception at all — and lets the Mapbox
   entries be _removed_.
2. **No visitor data leaves the site.** With a hosted basemap every visitor's IP address
   and viewport go to a third party on every pan. For an EU public body that is a GDPR
   question; self-hosted, it does not arise.
3. **No key, quota or account** to expire, leak or be billed against.

## Layout on the server

```
/srv/atgreen-basemap/
├── planet.pmtiles          # Protomaps OSM build, served with HTTP range requests
├── style.json              # generated by scripts/build-basemap-style.mjs
├── fonts/
│   ├── Noto Sans Regular/  # glyph ranges, {0-255,256-511,...}.pbf
│   ├── Noto Sans Medium/
│   └── Noto Sans Italic/
└── sprites/
    ├── dark.json  dark.png
    └── dark@2x.json  dark@2x.png
```

`/basemap/` on the site maps to this directory. It lives **outside**
`/opt/atgreen/releases/`: releases are rebuilt and pruned on every deploy, and the planet
file is far too large to ship with each one.

## One-time install

Run on `ghsci.hpc4ai.unito.it`. Nothing here touches the running app until the last step.

**1. The PMTiles CLI** — a single static binary from
[protomaps/go-pmtiles](https://github.com/protomaps/go-pmtiles/releases):

```bash
cd /tmp && curl -fsSLO https://github.com/protomaps/go-pmtiles/releases/download/v1.31.2/go-pmtiles_1.31.2_Linux_x86_64.tar.gz && tar xzf go-pmtiles_1.31.2_Linux_x86_64.tar.gz pmtiles && sudo install pmtiles /usr/local/bin/
```

**2. The planet, extracted to zoom 14.** Protomaps publishes a daily build at
`https://build.protomaps.com/YYYYMMDD.pmtiles` (the last few days are kept). `extract`
reads it with range requests, so only the zoom levels you keep are downloaded — not the
full ~120 GB file. Check the size first with `--dry-run`:

```bash
sudo mkdir -p /srv/atgreen-basemap && sudo chown ubuntu: /srv/atgreen-basemap
```

```bash
pmtiles extract https://build.protomaps.com/20260929.pmtiles /srv/atgreen-basemap/planet.pmtiles --maxzoom=14 --dry-run
```

```bash
pmtiles extract https://build.protomaps.com/20260929.pmtiles /srv/atgreen-basemap/planet.pmtiles --maxzoom=14
```

Zoom 14 is enough: the app fits cities at zoom 10–14, and MapLibre over-zooms vector
tiles smoothly beyond that. Zoom 13 roughly quarters the file again if disk is short.

**3. Fonts and sprites** from
[protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets). Only the three
Noto Sans stacks the dark style uses, and the dark sprite:

```bash
cd /tmp && rm -rf basemaps-assets && git clone --depth 1 https://github.com/protomaps/basemaps-assets.git && mkdir -p /srv/atgreen-basemap/fonts /srv/atgreen-basemap/sprites && cp -r "basemaps-assets/fonts/Noto Sans Regular" "basemaps-assets/fonts/Noto Sans Medium" "basemaps-assets/fonts/Noto Sans Italic" /srv/atgreen-basemap/fonts/ && cp basemaps-assets/sprites/v4/dark.json basemaps-assets/sprites/v4/dark.png basemaps-assets/sprites/v4/dark@2x.json basemaps-assets/sprites/v4/dark@2x.png /srv/atgreen-basemap/sprites/
```

**4. The style**, from a checkout of this repository (it needs `npm ci` for
`@protomaps/basemaps`). Every URL in it must be **absolute** — MapLibre 6 rejects a
relative sprite URL outright, and the script refuses to run without `--origin`:

```bash
node scripts/build-basemap-style.mjs --origin https://atgreen.hpc4ai.unito.it --out /srv/atgreen-basemap/style.json
```

**5. nginx.** Add to the atgreen `server` block, then `sudo nginx -t && sudo systemctl reload nginx`:

```nginx
# Self-hosted basemap. Static files, so nginx answers HTTP range requests
# natively — which is all PMTiles needs. No tile server.
location /basemap/ {
    alias /srv/atgreen-basemap/;
    etag on;       # lets the PMTiles client notice a mid-session update
    expires 1d;    # NOT add_header: any add_header in a location stops that
                   # location inheriting the server block's security headers
    default_type application/octet-stream;
    types {
        application/json       json;
        application/x-protobuf pbf;
        image/png              png;
    }
}
```

**6. Verify** before merging anything:

```bash
curl -sS -o /dev/null -w '%{http_code} %{content_type}\n' https://atgreen.hpc4ai.unito.it/basemap/style.json
```

```bash
curl -sS -r 0-126 -o /dev/null -w '%{http_code} %{size_download}B\n' https://atgreen.hpc4ai.unito.it/basemap/planet.pmtiles
```

Expect `200 application/json`, then `206 127B` — a 206 means range requests work.

## Then

1. **Merge the MapLibre pull request.** Not before step 6 passes: the production build
   loads `/basemap/style.json`, and if it 404s the map never finishes loading, which
   takes the choropleth down with it.
2. **Tighten the CSP** — remove the Mapbox hosts, which nothing requests any more:
   - `style-src 'self' 'unsafe-inline'`
   - `img-src 'self' data: blob:`
   - `connect-src 'self'`
3. **Revoke the Mapbox token** in the Mapbox account. It was public by design but had no
   URL restriction; once the migration is live nothing uses it, so there is no reason
   for it to exist.

## Refreshing

OpenStreetMap changes daily; the basemap does not need to. Every few months, repeat step 2
with a newer date to a temporary file, then move it into place — the PMTiles client sees
the new ETag and reloads cleanly:

```bash
pmtiles extract https://build.protomaps.com/YYYYMMDD.pmtiles /srv/atgreen-basemap/planet.next.pmtiles --maxzoom=14 && mv /srv/atgreen-basemap/planet.next.pmtiles /srv/atgreen-basemap/planet.pmtiles
```

If a new `@protomaps/basemaps` major changes the tile schema, regenerate `style.json`
(step 4) in the same change.

## Development

`npm run dev` does not use any of this. In development `src/js/map.js` points MapLibre at
[OpenFreeMap](https://openfreemap.org)'s dark style — free, no key, no account — so the app
runs on a laptop without a planet file on disk. The dev server has no CSP to block it.

The end-to-end suite uses neither: it intercepts `/basemap/style.json` with an empty,
valid style, so no test ever reaches a tile server.
